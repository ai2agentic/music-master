# DESIGN

## Aurora

- Hintergrund: sehr heller violetter bis türkiser Verlauf
- Flächen: halbtransparente, helle Karten mit sichtbarem Kontrast
- Akzent: dunkles Violett für primäre Aktionen
- Text: dunkles Blauviolett, gut lesbar
- Bedienung: grosse Klickflächen, klare Zustände, Tastatur bedienbar
